# 课堂转写笔记

把老师的课堂口语转写整理成可以对照讲稿复习的详细笔记。笔记固定包含三部分：基础知识预备、课堂讲授重点、总结。

这是一份开放的 [Agent Skill](https://agentskills.io/specification)。它不绑定某一门课，也不绑定某一个软件。任何能读取 `SKILL.md` 的助手都可以按它整理笔记。

课堂讲授重点按老师所讲内容分部分写。每一部分用连贯段落把定义、推理、例子和结论写完整，并附上能在原转写里搜到的讲稿锚点。复习时先看总结，卡壳就回到对应部分，再用锚点对照老师原话。

## 笔记里有什么

| 部分 | 写什么 |
|---|---|
| 基础知识预备 | 只补听懂这一讲所必需的概念：白话、精确定义、最小例子、它在第几部分用到 |
| 课堂讲授重点 | 按老师的话题顺序分成若干部分，用段落写详细笔记 |
| 总结 | 本讲主线、必须带走的结论、老师强调的易错点、自测和对照索引 |

老师没讲的补充会标成【笔记补充】。听不清或可能口误的地方会标成【转写存疑】。老师反复强调的内容会标成【老师强调】。

## 怎么用

把课堂转写贴到对话里，或给出文件路径，并说明要整理成笔记。例如：

```text
这是今天的课堂转写，请整理成可以对照讲稿复习的详细笔记。

讲稿在 lecture.txt，帮我写笔记。
```

只问某一个概念、例子或结论时，会按同样的对照标准回答那一部分，不另写全文笔记。

助手能写文件、且转写来自文件时，笔记写到同目录的 `<原名>-课堂笔记.md`。转写是直接粘贴的，或助手不能写文件时，完整笔记在回复里给出。

## 安装

文件夹名必须是 `lecture-transcript-notes`，`SKILL.md` 放在该文件夹根目录。

跨助手通用的位置是：

```text
个人：~/.agents/skills/lecture-transcript-notes
项目：<项目>/.agents/skills/lecture-transcript-notes
```

Cursor 会读取上面两处，也会读取 `~/.cursor/skills/` 和 `.cursor/skills/`。Claude Code 读取 `~/.claude/skills/` 和 `.claude/skills/`。某个助手只扫描自己的目录时，把同一个文件夹放进那个目录。

助手没有技能目录时，把 `SKILL.md` 和课堂转写一起发给它，并说明按该文件整理。

## 文件

```text
lecture-transcript-notes/
├── SKILL.md       # 整理笔记时遵循的说明
├── examples.md    # 粒度样本
└── README.md
```
